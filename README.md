# BlinkIT Grocery Sales Analysis | Power BI Dashboard

## Project Overview
This project focuses on analyzing BlinkIT grocery sales data using Microsoft Power BI. The dashboard provides insights into sales performance, product categories, outlet characteristics, and customer ratings.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## Dataset
The dataset contains information about:
- Item Fat Content
- Item Identifier
- Item Type
- Outlet Establishment Year
- Outlet Identifier
- Outlet Location Type
- Outlet Size
- Outlet Type
- Item Visibility
- Item Weight
- Sales
- Rating

## Project Objectives
- Analyze overall grocery sales performance.
- Understand sales across different item categories.
- Compare outlet performance.
- Analyze the impact of outlet size and location.
- Explore product ratings and visibility.

## Project Files
- `blinkit project.pbix` – Power BI dashboard.
- `BlinkIT Grocery Data.xlsx` – Original dataset.
- `Screenshots/` – Dashboard preview.

## Key Learnings
- Data visualization using Power BI.
- Working with Excel datasets.
- Creating interactive dashboards.
- Analyzing business performance through KPIs.
